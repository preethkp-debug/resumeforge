Import your details

Import from your LinkedIn data export

LinkedIn lets you download your own profile as CSV files for free. Upload that ZIP (or the individual CSVs) and we'll fill the form automatically.

  1. Go to LinkedIn → Settings → Get a copy of your data
  2. Choose "Want something in particular?" and select Profile, Positions, Education, Skills
  3. Click Request archive. LinkedIn emails you a ZIP within a few minutes.
  4. Drop the ZIP (or its CSVs) below.

Import from an existing resume PDF

Upload any resume PDF — including ones exported from Indeed, Google Docs, Word, or another resume builder. We'll do a best-effort parse of your contact info, experience, and education.

⚠ Heads up: PDF parsing is approximate. We'll fill what we can and dump the rest into the summary so you can move it around. Always double-check the result.

Fetch from a LinkedIn profile URL

Use Proxycurl to fetch a LinkedIn profile by URL. You'll need a Proxycurl API key (paid, ~$0.01–0.10 per fetch). Your key never leaves your browser.

⚠ Browser CORS limitation: Proxycurl's API may block direct browser calls. If the request fails with a CORS error, you'll need to deploy this site with a small backend proxy, or use the LinkedIn Data Export option above (which is free and works in-browser).
